# H3: independent graders and judge calibration

Date: 2026-11-17 (America/Los_Angeles). Branch: `homework/eval-harness-50`. H3 is complete. Main and the public application retain their accepted checkpoint.

This is the historical H3 checkpoint. H5 development subsequently introduced explicit grader v2/v3 revisions; the current span-selection contract is described in `homework/H3_GRADING.md`. Original H3 records and labels are preserved without replacement.

## Delivered

Exact, first-tool-call, rubric and unanswerable graders work over saved H2 results. Code checks independently validate source metadata, observed citations, requested units, expected values, first-call arguments and final applicant state without treating the production validator as the grading oracle.

Every open answer must satisfy correct, grounded, complete and in policy, plus its own items. Unanswerable cases also require a specific evidence gap and no invented answer. Missing/duplicate criteria, invalid booleans and fabricated quotes remain explicit grading errors.

Judge inputs omit candidate strategy/model/run identities and efficiency metrics. Requests and usage are separate from candidate records. No tools or shared candidate response state are available. The calibrated core/configuration/prompt revision and catalog are locked by `homework/grader_freeze.json`.
