# H4: scheduled evaluation, persistence and metrics

Date: 2026-11-17 (America/Los_Angeles). Branch: `homework/eval-harness-50`. H4 is complete. Main, the public application, H1 data, H2 candidate code and H3 grader revision remain unchanged.

## Delivered and verified

The CLI prepares or explicitly runs an immutable experiment connecting candidate execution to grading. It saves each stage before proceeding, supports bounded execution and resume, and recomputes CSV/Markdown/JSON reports offline. Formal schedules contain 50 baseline plus 150 Agent executions; variants are interleaved while preserving repeat identity.

Each plan pins candidate/grader/runner hashes, H1 files, catalog, date/model/limits, grading freeze, pricing/app configuration, dependency lock and runtime versions. Resume rejects changed fingerprints. Failed, timed-out and errored results are retained. Corrupt evidence, foreign pairings, duplicate trace IDs and unscheduled directories are rejected.

A crash after a request may leave billing/outcome uncertain. The started marker survives, resume records an unknown interruption and does not reissue the stage. Candidate and judge records remain separate, and a candidate saved before interruption can be graded without running again.

## Arithmetic fixture, not a benchmark

A separate hand-authored two-task fixture uses Agent vectors:

- d01: [pass, fail, pass].
- d02: [fail, fail, fail].

Expected and observed: pass@3 = 1/2, pass^3 = 0, flip list = d01. Both the baseline and designated first Agent repeat have 1/2 accuracy in this artificial fixture; each denominator stays two.

With authored latencies, the baseline mean is 4,500 ms and p95 is 8,000 ms, including its failed tail. Agent repeat 1 has mean 3,500 ms and p95 5,000 ms. An authored input of 100 tokens with 80 cached, plus 20 output tokens, contributes 120 tokens, not 200. Judge latency is excluded from candidate latency.

These values are software fixtures, not measured Agent performance. Fixture reports carry a prominent offline/non-benchmark label. A missing repeat is represented as null, leaves scheduled denominators unchanged and suppresses final stability values. Judge errors are unresolved, never silently treated as passing or dropped.
