# M3.5 recommendation pilot checkpoint

Date: 2026-11-16. This milestone completes a small input → sourced recommendation → budget-update loop in the fixed baseline. M4 has not started. User acceptance is pending.

## Implemented behavior

- Degree completion, credential status, academic field/country and GRE scores/date/format are explicit form fields. Unknown values stay unknown. No GPA conversion or GRE minimum is invented.
- Current public catalog: 10 programs / 30 official sources; original M1 seed and snapshots retained. Source bindings and hashes are checked before import. A local public-database backup was taken before importing the current seed.
- Formal cards show the planning-tier reason, official cohort evidence, tuition formula and assumptions, goal-fit feature, eligibility checks, limitations, source links and a preparation checklist. Submission of application documents is not asserted.
- Cohort-based Lottery / Reach use documented conservative-v1.1 thresholds. They are planning labels, not personal admission probabilities. Target/Safer require two independent comparable cases; no qualifying cases are currently available.
- MSAII supplies the real positive path: 2025 official 58 offers / 526 applications, four 2026–27 billed semesters plus required pre-arrival summer tuition, USD 133,500–137,400. MCDS remains pending despite its cohort evidence because entry requirements are not fully verified.

## Actual verification

`python -m scripts.verify_m35 --live-model` passed 107 automated checks and the final two real OpenAI requests. Offline stubs and real API results are distinguished. The final acceptance session used a fictional applicant only, with no validation errors:

| Step | Actual result |
| --- | --- |
| USD 140,000 tuition-only budget | One supported MSAII Lottery recommendation; explicit cohort-based limitation and exact summer-inclusive tuition. |
| Change my tuition budget to 100000 | MSAII removed for exceeding budget; GPA, degree, English result, GRE, goal, coursework and experience preserved. MCDS remains pending. |
| Target / Safer | Empty, with a comparable-case evidence shortfall. |

| Form save | Exact USD cents preserved; degree, GRE and other background preserved semantically; all UI text remains English. |
| Clean release without local DB or secrets | Cold start, process restart and cache-loss rebuild passed; all recovered 10 programs / 30 sources, identical data hash and fresh profile; zero model calls. |

## User acceptance

Open [the public app](https://gradmatch-nathan-sie.streamlit.app/). Confirm release M3.5, 10 programs and 30 evidence sources. Then:

1. Click **Load tiering example (USD 140,000)**.
2. Enable **Allow paid model calls for this session** under Model setup and usage.
3. Click **Generate / rerun**. Expect MSAII in Lottery, with tuition up to USD 137,400, source links and a clear statement that cohort selectivity is not your admission probability. MCDS is pending; Target/Safer are empty.
4. Send **Change my tuition budget to 100000**. Expect MSAII removed with a budget reason. Check that the current structured profile still contains the original degree, GPA, English, GRE, coursework, experiences and goal.
5. Download the session JSON if desired. Rerendering or opening details should not create model calls.

The sample is intentionally fictional and expensive so that the currently verified program can exercise the complete loop. It is not an example of an affordable personal shortlist. This milestone does not complete all four tiers or the broader catalog; live source tools and wider evidence collection remain later work.
