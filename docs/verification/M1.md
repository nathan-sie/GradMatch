## 用户手动验收步骤

打开 `http://127.0.0.1:8501`；若仍显示旧页，刷新。The current UI is English; use **Run M1 checks** and the English labels below. 若服务已停止：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

1. 页面顶部应显示 **8 个项目、20 条来源**，进入 M1 资料与规则验收页。
2. 展开资料覆盖表，确认只有 3 个可复算费用，其余为待核实，并明确列出所有项目的其他资格和分档证据缺口。
3. 保持默认合成输入，点击 **Run M1 checks**。70,000 预算下，UW 与 Northeastern 的费用项显示 **Meets checked requirement**，USC 的费用项显示 **Does not meet requirement**；不能据此把任何项目视为已获得推荐资格。
4. 将预算改为 50,000，再点击运行。UW 与 Northeastern 的费用项应变为不满足，GPA、英语与其他表单内容保留。
5. 选择 UW 项目，查看费用公式和来源。总 GPA 不直接代替最后 60 学期学分 GPA；把 **GPA calculation scope** 改为 **Last 60 semester credits** 并重新提交，3.5/4 的 GPA 项应满足。
6. 可选英语边界：选 IELTS，手动把总分改为 7。不提供单项时，UCI 英语项应为待核实；提供全部单项且口语为 5.5 时，应为不满足。不要把原 TOEFL 的 100 自动转换成 IELTS。
7. 展开官网证据，打开链接抽查至少一项学费和一项资格/截止规则，确认来源支持字段；检查单项状态旁边的来源 ID。
