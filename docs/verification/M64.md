# M6.4 evaluation harness checkpoint

The benchmark runner exercises the same snapshot recommendation service as GradMatch. The development suite covers initial recommendations, follow-ups, clarification, evidence gaps, and shortfalls. It uses fictional profiles and the pinned 83-program catalog as of November 21, 2026. The fixed baseline, ReAct, and plan-and-replan receive the same scripted inputs in separate sessions.

## Reproduce

Start from the repository root with the project environment installed. Choose a fresh run directory for a new experiment.

```powershell
python -m scripts.run_benchmark --run-dir runs/m64-local --dry-run
python -m scripts.run_benchmark --run-dir runs/m64-local --resume --max-new-runs 9
python -m scripts.run_benchmark --run-dir runs/m64-local --resume
python -m scripts.summarize_results --runs runs/m64-local
python -m pytest -q tests/test_benchmark.py
```

The manifest pins the snapshot, task inputs, reference criteria, engine, and dependency versions. Each attempt saves the submission, output, and event log for every completed turn, followed by the grade and service metrics. A resumed run skips finished attempts. It records interruptions before starting a new attempt. Summary rates use the scheduled first attempts as the denominator, including rows with errors, interruptions or missing results. Latency and turn averages include only rows with those measurements, and the summary reports their sample counts.

Task inputs are in `eval/development/tasks.jsonl`. The grader reads `eval/development/oracles.jsonl` separately and checks specific outcomes, including cited evidence, recommendation eligibility, clarification, and unchanged profile fields. The missing-tuition case removes a reviewed tuition record and its program's official source excerpts before building the recommendation pool. Community records remain available as preliminary evidence.

The accepted local run completed 9 executions in the first batch and 36 after resuming. The earlier probe recorded 42/45 passes. The three failures shared a case that omitted the applicant's answer to a TOEFL date question. The corrected script explicitly declares the date unknown. Each strategy then asks for it, retains the same task, and keeps the English requirement pending after the reply.

These results are for fixture-driven checks of the harness and service. Provider token totals, costs, and model quality scores require real executions. The formal split validates the required 210-task distribution and disallows development template families. Formal task and safety authoring, review, and live measurement are subsequent checkpoints.
